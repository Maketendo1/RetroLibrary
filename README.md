# RetroLibrary

포터블 레트로 게임 검색기 RetroLibrary의 공식 배포 및 업데이트 저장소입니다.

## 다운로드

[Releases](https://github.com/Maketendo1/RetroLibrary/releases)에서 버전별 서명된 프로그램 ZIP과 수동 패치 ZIP을 제공합니다.

- `RetroLibrary-program-<버전>.zip`: 검색기의 온라인 업데이트에서 사용하는 프로그램 패키지
- `RetroLibrary-patch-<버전>.zip`: 독립 업데이트 도구를 포함한 수동 패치

ROM, BIOS, 게임 DB, 개인 기록, 세이브 및 서명 개인키는 배포 자료에 포함하지 않습니다. 기존 설치본의 업데이트 용도이며 게임 자료는 별도로 유지합니다.

공개 태그는 배포 버전을 식별합니다. 실제 제작 코드의 커밋은 각 Release 설명과 서명된 프로그램 명세에 기록합니다.
